# StudyTED v1.0.0

YouTube 자막으로 영어를 공부하는 데스크톱 앱 첫 배포입니다.

## 주요 기능
- 채널을 한 번 등록하면 영상·자막을 한 번에 수집 (이미 받은 영상은 메타 갱신 건너뛰기)
- 듣기 모드 / 자막 모드(현재 문장 하이라이트, 문장 복사·전송)
- 문장 노트 저장 + AI 구문 분석 (영어 구문 + 한국어 뜻/설명)
- 저장한 문장 목록, JSON/Markdown 내보내기로 공유
- 설정에서 OpenRouter 키·모델 선택 (가성비 추천, 즐겨찾기, 가격 표시)
- 앱 안에서 새 버전 확인 → 내려받기 → 설치 후 자동 재시작
