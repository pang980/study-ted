# StudyTED v1.0.2

자막을 못 가져오던 문제를 고친 버전입니다.

## 고친 것
- **자막 가져오기 실패 수정** — yt-dlp 기본 플레이어 클라이언트(visionos)가 "This video is not available" 로 거절하던 영상(예: Bluey 공식 채널)도 자막을 받아옵니다. `default,android` → `android,ios` 순서로 다시 시도합니다.
- **자막 전용 요청이 포맷 오류로 중단되던 문제 수정** — `--ignore-no-formats-error` 로 재생 포맷을 고르다 죽지 않게 하고, 실패해도 다음 클라이언트·언어 조합을 끝까지 시도합니다.
- **실패 이유를 한국어로 안내** — `yt-dlp 종료 코드 1: ERROR: ...` 대신 "YouTube 가 이 동영상을 제공하지 않습니다 / 자동 요청 차단" 같은 문장으로 보여 줍니다. 채널 목록과 수집 결과에도 `자막 실패 N개` 를 표시합니다.

## 참고
- 이미 수집한 채널도 `전체 채널 수집` 을 한 번 더 실행하면 자막이 없는 영상의 자막을 새로 받아옵니다(이미 받은 자막은 건너뜁니다).
- 필요한 자막이 없는 영상은 실패 목록에 남고, 다음 수집 때 다시 시도합니다.

## 업데이트 방법
- 앱을 켜면 홈 상단에 새 버전이 표시됩니다. 버튼을 누르면 내려받아 설치하고 자동으로 다시 시작합니다.
- 설치 파일: StudyTED-Setup-1.0.2.exe
