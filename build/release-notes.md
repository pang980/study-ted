# StudyTED v1.0.1

AI 분석 정확도와 문장 노트 사용성 문제를 고친 버전입니다.

## 고친 것
- **선택한 문장이 아니라 동영상 제목을 해석하던 문제 수정** — AI 분석 프롬프트가 분석 대상 문장을 메시지 마지막에 오도록 바뀌었습니다.
- **삭제 버튼이 동작하지 않던 문제 수정** — 확인 창에서 "삭제"를 눌러도 취소로 처리되던 오류입니다.
- **문장 수정 창이 사라지던 문제 수정** — 창 밖을 잘못 눌러도 닫히지 않습니다. 닫기는 ✕·취소·Esc 로만 됩니다.

## 문장 노트
- 문장을 누르면 해석·구문 분석 상세가 바로 열립니다(같은 행에서 펼쳐짐).
- `분석 보기` 로 펼친 내용이 360px 높이에서 잘리지 않고 전부 보입니다.
- 저장된 분석은 제목 줄·안내 문구 없이 `1. 문장 해석` + `2. 구문 분석` 만 보여 줍니다.
- `AI 다시 분석` 버튼은 없앴습니다. 기존 문장을 고치려면 `수정` 에서 직접 입력하거나 학습 화면에서 다시 분석하세요.

## 업데이트 방법
- 앱을 열면 홈 상단에 새 버전이 표시됩니다. 버튼을 누르면 내려받아 설치하고 자동으로 다시 시작합니다.
- 설치 파일: StudyTED-Setup-1.0.1.exe
