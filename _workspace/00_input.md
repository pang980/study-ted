# Input Summary

## 사용자 요청 (원문 요약)

유튜브 동영상을 활용한 영어 학습 프로그램 제작.

- 구현 스택: **일렉트론 + SQLite**
- 유튜브 **채널 주소**를 입력하면 그 채널의 동영상을 순차적으로 수집(제목 / 동영상 주소 / 자막)
- 수집한 데이터를 기반으로 영어 학습 시스템 구성
  1. **듣기 모드**: 자막 없이 동영상만 재생
  2. **자막 모드**: 자막을 켜고, 오른쪽 패널에 전체 자막을 표시하며 **현재 재생 중인 문장을 하이라이트**. 필요한 문장을 복사 가능
  3. **문장 저장 모드**: 자막에서 문장을 복사해 저장. 영어 문장을 입력하고 **AI 구문분석** 버튼을 누르면 AI가 이해하기 쉽게 풀어서 설명 + 예문 출력. **AI 없이 수동 입력도 가능**
- 저장해야 하는 자료: 유튜브 제목, 유튜브 주소, 문장들, 해석, 자막
- **학습한 자료(문장) 목록**을 만들어 데이터가 계속 쌓이게 할 것
- 이 내용을 **다른 사람에게 공유**할 수 있게 할 것
- 설정: **오픈라우터(OpenRouter) 키** 입력, **LLM 모델 선택**, **자주 쓰는 모델 / 즐겨찾기 모델** 기능
- UI는 첨부 이미지(`UI.png`)를 참조

## 프로젝트 목표

로컬 데스크톱(Electron)에서 동작하는 유튜브 기반 영어 학습 워크벤치.
채널 단위로 영상과 자막을 로컬 SQLite에 축적하고, 문장 단위 학습 노트를 AI로 확장하며, 그 결과를 파일로 내보내 공유할 수 있게 한다.

## 핵심 기능

| 번호 | 기능 | 우선순위 |
|---|---|---|
| F1 | 채널 주소 입력 → 채널 메타데이터 + 동영상 목록 + 자막 수집 | P0 |
| F2 | 듣기 모드 (자막 끔) 재생 | P0 |
| F3 | 자막 모드 (자막 켬 + 전체 자막 패널 + 현재 문장 하이라이트 + 문장 복사) | P0 |
| F4 | 문장 저장 + AI 구문분석 (해석 / 구문 분석 / 주요 표현 / 예문) | P0 |
| F5 | 수동 입력 모드 (AI 미사용) | P0 |
| F6 | 학습한 문장 목록 (검색 / 태그 / 정렬 / 즐겨찾기) | P0 |
| F7 | 내보내기(공유용) / 가져오기 | P1 |
| F8 | 설정: OpenRouter 키, LLM 모델 선택, 즐겨찾기·자주 쓰는 모델 | P0 |
| F9 | 채널 관리 (등록 채널 목록, 재동기화, 삭제) | P1 |
| F10 | 학습 자료 뷰 (영상/채널 기준 묶음 보기) | P1 |

## 기술 스택 (확정)

- Runtime: Electron 44 (Chromium + 내장 Node 22)
- UI: Vanilla HTML/CSS/ESM (번들러 없음). 커스텀 `app://` 프로토콜로 렌더러 로드
- DB: `node:sqlite` (`DatabaseSync`) — Electron 내장 Node 사용, 네이티브 모듈 빌드 불필요
- 유튜브 수집: provider 계층
  - 1순위: `yt-dlp` (설정에서 자동 다운로드 / 경로 지정)
  - 2순위: 자체 Innertube + HTML 파서 (채널·영상 메타데이터, 자막 트랙 탐지)
- AI: OpenRouter Chat Completions (메인 프로세스에서만 호출)
- 저장 위치: `app.getPath('userData')/study-ted.db`

## 제약 조건

- OpenRouter API 키는 렌더러에 노출하지 않는다. 메인 프로세스 + `safeStorage` 암호화 저장.
- `.env` 값은 출력·기록하지 않는다.
- 모든 텍스트 파일은 UTF-8 without BOM 유지. 한글 깨짐 금지.
- 파일 수정은 `_workspace/04_file_map.md` 범위 내에서만.
- 사용자 명시 요청 없이는 commit / push / 배포 금지.
